
# 📊 Social Media Usage Analysis Dashboard

This Power BI project analyzes social media usage patterns across Facebook, Instagram, and WhatsApp. The data is broken down by age, city, and gender to reveal insights into platform popularity and demographic engagement.

## 📁 Project Overview

The dashboard provides an intuitive visualization of:

- 📉 **Average Usage** across Facebook, Instagram, and WhatsApp  
- 👥 **Demographic Insights** by age, city, and gender  
- 📌 **Geographical Usage Patterns** across Indian cities  
- 🕵️‍♀️ **Age-based Trends** in social media consumption  
- 📊 **Platform Comparisons** in terms of usage and popularity
- 

## 🔍 Key Highlights

- **Average Facebook Usage**: 250.92  
- **Average Instagram Usage**: 720.18  
- **Average WhatsApp Usage**: 1.15K  
- **Total Average Social Media Usage**: 2.12K  

### Most Used Social Media Platforms

- WhatsApp > Instagram > Facebook  
- Visualized with pie chart and tree map for clarity  

### Most Active Age Groups

- Predominantly aged between 21–26  
- Highest spikes in usage between 18–25, as shown in the line graph  

### City & Gender Insights

- Usage metrics vary widely across cities  
- Coimbatore shows the highest Facebook usage among males and females  
- Color-coded bar chart shows increase, decrease, and other trends
